OBJETIVO
Separar da PR #58 somente a melhoria do backend C++ Vulkan para carregamento de driver Adreno customizado, fallback para o loader do sistema e seleção/validação de GPU e fila. Esta PR não altera o importador Kotlin nem a UI de configurações.

PORTADO
- [x] resetLoader centraliza limpeza do Dispatch, fecha handle e zera usingCustomDriver.
- [x] loadLoader valida os símbolos vkGetInstanceProcAddr e vkCreateInstance antes de aceitar um loader.
- [x] Fallback do driver customizado para libvulkan.so quando o driver customizado não carrega ou não passa a probe.
- [x] Probe Vulkan verifica enumeração de dispositivos e extensões exigidas em todos os dispositivos enumerados, em vez de presumir que o primeiro dispositivo serve.
- [x] Seleção de GPU exige API mínima, extensões de exportação e fila graphics+compute antes da criação do dispositivo.
- [x] loadInstanceFunctions/loadDeviceFunctions verificam todos os ponteiros usados pelo backend.
- [x] Fallback para driver do sistema também quando o driver customizado passa a probe mas falha durante a criação do contexto.
- [x] Preservado o CMake atual: libadrenotools já está integrado na base game-mode-m2-dev; não foi duplicado nem substituído.
- [x] Preservada a API DriverConfig/GLRetroViewData atual; não foram alterados contratos JNI ou Kotlin.

PONTOS DE ATENÇÃO
- [ ] Revisar comportamento em aparelhos com múltiplos dispositivos Vulkan e núcleos que negociam dispositivo/fila próprios.
- [ ] Confirmar que a recuperação após falha do custom driver restaura corretamente estado de negociação e recursos parciais.
- [ ] Adicionar testes nativos automatizados se a infraestrutura atual permitir injeção de loader/Vulkan fake.
- [ ] CI Android/NDK deve compilar todas as ABIs configuradas; validar especialmente arm64-v8a.
- [ ] Teste físico com Turnip e fallback para driver do sistema no Motorola Edge 30 Fusion.
- [ ] Confirmar logs de falha e garantir que uma falha de Turnip não impeça jogos que funcionam com o driver padrão.

NÃO INCLUÍDO
- Importador multi-driver AdrenoTools e migração de preferências.
- UI de seleção/importação de múltiplos drivers.
- Alterações no GameModeSettings, VulkanDriverManager ou GameModeActivity.
- Alterações em tandem-latest.

SEGURANÇA
- PR será mantida em Draft até CI e revisão.
- Nenhum merge automático.
- PR #58 permanece aberta até que todos os blocos sejam reconciliados e as dependências resolvidas.
